## Найденные и исправленные проблемы

- Старый контракт разрешал основной экспорт с ошибками. Теперь доступен только диагностический комплект до устранения ошибок/конфликтов.
- Старые тесты ожидали запрет нескольких листов, отсутствие группировки тысяч и блокировку разных названий; ожидания обновлены согласно заданию, добавлены независимые эталоны.
- Первый браузерный прогон обнаружил горизонтальный выход декоративной волны на 768 px. CSS исправлен; итоговый повтор на всех ширинах прошёл.
- Замер выявил повторные вычисления `sheet.max_row` на каждой записи при экспорте. Запись по известным координатам сократила эту часть работы; повторный замер приведён выше.
- Общая pytest-фикстура перенесена в `conftest.py`; окончательный прогон прошёл полностью.
