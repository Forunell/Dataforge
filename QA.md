## Исправления по результатам реальных прогонов

1. Тест истечения сессии первоначально предполагал, что монотонные часы всегда больше часа. Исправлен расчет тестового времени: текущее значение минус 3601 секунда; повторный прогон успешен.
2. В первом браузерном прогоне строгая политика `no-referrer` давала Origin, отклоняемый локальной защитой формы. Заменена на `same-origin`; чужие Origin по-прежнему отвергаются. Повторный E2E прошел на всех трех ширинах.

## Воспроизведение

```powershell
.\.runtime\python.exe -m pytest -q --junitxml=artifacts\pytest.xml
.\.runtime\python.exe -m ruff check .
.\.runtime\python.exe -m compileall -q dataforge scripts tests
.\.runtime\python.exe -m pip check
```

Для браузера запустить `start.cmd`, затем в другом окне:

```powershell
.\.runtime\python.exe scripts\browser_check.py
```

Скриншоты: `artifacts/step-{1..4}-{360,768,1440}.png`. ZIP, скачанные настоящим браузером: `artifacts/browser-export-{360,768,1440}.zip`.
