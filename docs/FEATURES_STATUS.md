# Состояние возможностей — 07.11.2026

| Возможность | Состояние и границы |
|---|---|
| Существующий стек | Сохранён Python/FastAPI/Jinja2/openpyxl; новые зависимости не добавлены |
| Пустое состояние, демо | Реализовано; синтетические источники помечаются отдельно, включая смешанную загрузку |
| CSV | Реализовано: UTF-8/BOM, ручной CP1251, три разделителя, кавычки, переносы, пустые записи |
| XLSX | Реализовано: явный выбор листа, в том числе если первый пустой; формулы не выполняются |
| Независимая замена | Реализовано; другой файл и его рабочие значения сохраняются, отчёт и стек отмены сбрасываются |
| Сопоставление | Реализовано: 7 полей, необязательные валюта/остаток/категория/вариант; неоднозначные подсказки не выбираются |
| Правила | Реализованы обязательность SKU/названия, уникальность, знак цены/остатка, целый остаток, порог цены, пробелы/регистр названий |
| Ключ | SKU либо пара SKU+вариант без конкатенации и риска совпадений разделителей |
| Денежные значения | Decimal, подтверждённые группировки тысяч, неоднозначность отдельной ошибкой; до 18 цифр/6 десятичных; конвертации валют нет |
| Сравнение | Новые, отсутствующие, изменённые, неизменённые, конфликты; изменённые поля с обоими номерами строк и названиями колонок |
| Поиск и таблицы | Поиск SKU/название; сортировка SKU/название/статус; серверная пагинация по 50 товаров и проблем |
| Метрики | Фактические проблемы, непересекающиеся категории строк, качество; категории сравнения считаются по ключам, неполные ключи — отдельно по строкам |
| Исправления | Ручные и массовые с предварительным просмотром; последние 20 операций отменяемы, полный возврат к оригиналам |
| История | Только текущая сессия. `edits.csv` — итоговые отличия от оригинала, не полный хронологический журнал всех действий |
| Экспорт | CSV/XLSX/ZIP/JSON; основной каталог заблокирован при ошибках/конфликтах; диагностическая рабочая копия остаётся доступной |
| Сохранность | Все исходные колонки доступны в raw_json; строки не удаляются; исходные файлы не перезаписываются |
| Приватность | Локальный сервер, память процесса; запросы к сторонним адресам в E2E отсутствуют; localStorage не используется |
| Интерфейс | Зелёный референс, украинские тексты; Edge 390/768/1440 проверен |
| Производительность | Синтетические 2000+2000 строк, XLSX, 64 колонки, CSV 1.856 МБ проверены; результаты в artifacts/performance.json |
| Только браузер | Не реализовано: сохранена существующая локальная серверная архитектура |
| Облако, аккаунты, интеграции | Не реализованы и не подключались |
| Объединение в магазинный каталог | Не реализовано; экспорт содержит A и B с источниками |
| Полный аудит доступности/офисных приложений | NOT TESTED; подробности в QA_REPORT.md |

Ограничения: 2 МБ/файл, 2000 записей, 64 колонки, 1000 символов/поле, 30000 символов JSON-снимка строки; XLSX до 16 МБ после распаковки и 1000 ZIP-элементов. Эти ограничения не являются гарантией времени выполнения для любого файла.

Показатель «устранено» сравнивает набор `(источник, строка, поле, код ошибки)` с первой проверкой текущей пары файлов. Отключение правила также может убрать ошибку из этого набора; это прямо поясняется в интерфейсе. Количество фактически изменённых ячеек показывается отдельно.
