# DataForge: коротка інструкція

## 1. Запуск і завантаження

Запустіть `start.cmd` і відкрийте http://127.0.0.1:8765. Для першого запуску на іншому комп’ютері спочатку виконайте `setup.cmd`.

Додайте **A — базовий прайс**, **B — оновлений прайс** через вибір файлу або перетягування. Натисніть «Прочитати файли». Для XLSX з кількома аркушами явно виберіть один аркуш кожної книги. Інші аркуші не порівнюються. Після читання видно назву, розмір, формат, кількість рядків та перші п’ять записів.

CSV: UTF-8 з BOM або без нього; кома, крапка з комою чи табуляція. Якщо авто не спрацювало, розкрийте «Параметри читання CSV» та виберіть роздільник. Windows-1251 вмикається лише вручну. Після помилки файли потрібно вибрати повторно.

Для проби є «Відкрити демо». Синтетичні джерела позначені «Демодані». Якщо замінити тільки один демофайл, позначка залишиться для другого.

## 2. Колонки й правила

Перевірте відповідність SKU, назви, ціни. Валюта, залишок, категорія та варіант необов’язкові. Без валюти ціни між джерелами не порівнюються: валюту не вгадуємо. Неоднозначні заголовки потрібно зіставити вручну.

Для різних варіантів одного товару виберіть «SKU + варіант» та обидві колонки варіанта. Увімкніть необхідні перевірки. Поріг ціни створює попередження лише при **перевищенні** порога; нульова базова ціна обробляється окремо. Назви можна порівнювати без урахування регістру та зайвих пробілів.

Підтвердьте спільну систему ключів A/B, щоб отримати порівняння, і натисніть «Перевірити дані». Без цього прапорця виконується лише перевірка якості рядків.

Приклади чисел: `1234.56`, `1234,56`, `1 234,56`, `1,234.56`, `1.234,56`. Значення `1,234` неоднозначне: виправте його на `1234` або `1.2340`, залежно від змісту. Науковий запис не підтримується. До 18 цифр загалом та 6 десяткових знаків. Курс валют не застосовується.

## 3. Результат та виправлення

Фільтруйте нові, відсутні, змінені, незмінені товари, конфлікти, помилки й попередження. Пошук працює за SKU/назвою, сортування — за SKU, назвою та статусом. Результати й проблеми показуються по 50 записів. «Переглянути» розкриває значення полів A/B.

Помилка має джерело, файл, аркуш, номер запису, колонку, значення та пояснення. Номер CSV — **логічний запис**, починаючи з 2 після заголовка; переноси в лапках не змінюють цей номер. Порожні записи зберігаються.

У «Виправленнях» виберіть джерело/колонку, операцію, для однієї комірки — номер рядка й нове значення. Спочатку натисніть «Переглянути правки», перевірте кількість та приклади, лише потім «Застосувати». Усі зміни виконуються в робочій копії. Після застосування перевірка оновлюється автоматично, старий експорт стає недоступним.

Масові операції: крайні пробіли, верхній/нижній регістр, однозначні числа. Пропуски SKU та дублікати автоматично не виправляються. Неоднозначні числа пропускаються і залишаються у звіті. Скасування — останні 20 операцій; «Відновити початкові значення» повертає всі комірки. Правила нормалізації діють окремо: вимкніть їх у кроці 2, якщо потрібно скасувати й їхній результат.

Якість = рядки без жодної проблеми / всі рядки A+B × 100%. Категорії «без проблем», «лише попередження», «з помилками» взаємовиключні. Кількість порушень — інший показник: один рядок може мати декілька.

## 4. Експорт і завершення

Підтвердьте перегляд і створіть експорт. Якщо залишилися критичні помилки або конфлікти зіставлення, `normalized.csv` недоступний. Натомість можна отримати `review_rows.csv` — **не очищений каталог**, а робочу копію з усіма рядками, та звіти.

`issues.csv` — порушення; `changes.csv` — зміни полів A/B; `comparison.csv` — усі результати зіставлення; `edits.csv` — відмінності від оригіналу; `transformations.csv` — перетворення правил; `report.json` — підсумок із датою, правилами та статусом. `summary.xlsx` містить ті самі таблиці. ZIP об’єднує всі файли.

Основний каталог містить **обидва джерела**, а не автоматично об’єднаний магазинний прайс. У CSV формульний текст отримує захисний апостроф; початкові значення залишаються в `raw_json`. В Excel використовуйте XLSX або імпортуйте CSV зі SKU як текстом, щоб не втратити нулі.

Для заміни одного джерела відкрийте крок 1 й виберіть лише відповідний файл. Друге джерело збережеться; звіт та історія скасування скинуться. Для завершення натисніть «Почати заново». Закриття вкладки не очищає локальний сервер негайно; сервер тримає сесію до скидання, зупинки або очищення після години бездіяльності під час наступного запиту.
