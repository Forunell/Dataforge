# DataForge

Локальный инструмент для проверки и сравнения двух прайсов CSV/XLSX. Украинский интерфейс, явное сопоставление колонок, проверка качества, обратимые исправления и отчёты. Существующая архитектура **Python + FastAPI + Jinja2 + openpyxl** сохранена; новые зависимости не добавлены. Это самостоятельный учебный проект, без вымышленных клиентов и отзывов.

## Запуск на Windows

В текущем проекте Python и библиотеки уже установлены в `.runtime`:

```powershell
cd D:\proek\DATAFORGE
.\start.cmd
```

Откройте **http://127.0.0.1:8765**. Оставьте окно сервера открытым. `Ctrl+C` завершает работу сервера.

При первом запуске на другом компьютере сначала выполните:

```powershell
cd D:\proek\DATAFORGE
.\setup.cmd
.\start.cmd
```

Установщик требует сеть для Python и библиотек; устанавливает всё внутри проекта, не меняет PATH. Глобальные Node.js/Python не нужны. Прямая команда без оболочки:

```powershell
.\.runtime\python.exe -m uvicorn dataforge.app:app --host 127.0.0.1 --port 8765
```

Сборщика фронтенда нет. Проверка сборки — компиляция Python и загрузка шаблонов/API в тестах. Не запускайте несколько workers: сессии находятся в памяти одного процесса.

## Рабочий сценарий

1. Загрузите A — исходный прайс и B — обновлённый. Для многолистового XLSX выберите один лист. Первые пять записей доступны для проверки. «Відкрити демо» открывает явно помеченные синтетические данные.
2. Подтвердите SKU, название, цену; при наличии — валюту, остаток, категорию, вариант. Выберите SKU либо SKU+вариант, правила качества и подтвердите общую систему ключей для сравнения.
3. Найдите новые, отсутствующие, изменённые и неизменённые товары; исследуйте конфликты. Есть поиск, сортировка и страницы по 50 товаров/проблем. Разные названия показываются как изменение после подтверждения ключа. Дубли/ошибки блокируют однозначное сопоставление.
4. Исправьте ячейки в рабочей копии. Ручные и массовые операции сначала показывают количество и примеры «до → после», затем требуют применения. Последние 20 операций отменяются; полный сброс возвращает исходные значения. Файлы на диске не меняются.
5. Подтвердите результат и скачайте отчёты. При критических ошибках **или конфликтах сопоставления** основной каталог недоступен. Диагностические отчёты и рабочая копия остаются доступными.

Можно заменить только один файл: второй сохраняется, прежний отчёт и стек отмены сбрасываются. При неудачной загрузке предыдущая рабочая пара сохраняется.

Простой пример: `TEST_DATA/clean_a.csv` + `TEST_DATA/clean_b.csv` → 6 исходных строк, 1 неизменённый, 1 изменённый, 1 новый и 1 отсутствующий товар, 0 проблем, качество 100%. Пример с ошибками: `supplier_a.csv` + `supplier_b.xlsx` → 22 строки, 12 ошибок, 4 предупреждения, качество 45,5%. Эталоны зафиксированы независимо в `TEST_DATA/golden_results.json` и проверяются тестом.

## Числа, ключи и качество

SKU всегда текстовый; пробелы/регистр не меняются без выбранного правила. Составной ключ хранится парой значений. Дубли никогда не удаляются и не объединяются автоматически.

Decimal разбирает `1234.56`, `1234,56`, `1 234,56`, `1,234.56`, `1.234,56` и однозначные повторные группировки. Одиночное `1,234` или `12.345` требует уточнения: это может быть дробь или группировка тысяч. До 18 цифр суммарно и 6 после десятичного знака; научная нотация не принимается. При нулевой базовой цене процент изменения не выдумывается, создаётся предупреждение. Валюты не конвертируются. При разных или неизвестных валютах сравнение цены блокируется; остаток можно сравнить отдельно.

**Качество = строки без ошибок и предупреждений / все строки A+B × 100%, округление до 0,1%.** Категории строк взаимоисключающие: без проблем, только предупреждения, с ошибками. Количество нарушений считается отдельно, поскольку у одной строки их может быть несколько. Категории сравнения относятся к ключам, а не к исходным строкам; неполные ключи учитываются отдельными конфликтами строк.

Правила обязательности SKU/названия, уникальности, неотрицательных чисел и целого остатка настраиваются; формат чисел проверяется всегда. Показатель «устранено» сравнивает набор ошибок с первой проверкой этой пары. Изменение правил тоже может убрать ошибку; количество реально исправленных ячеек показано отдельно.

## Что входит в экспорт

| Файл | Содержимое |
|---|---|
| `normalized.csv` | Только при отсутствии ошибок/конфликтов: все строки обоих источников и нормализованные поля |
| `review_rows.csv` | Вместо основного каталога при проблемах: диагностическая рабочая копия, **не очищенные данные** |
| `issues.csv` | Источник, файл, лист, строка, колонка, тип, серьёзность, исходное/текущее значение, пояснение |
| `changes.csv` | События по изменённым полям, названия колонок, номера записей A/B, значения до/после |
| `comparison.csv` | Все результаты сопоставления, включая неизменённые и конфликты |
| `transformations.csv` | Предлагаемые преобразования выбранных правил |
| `edits.csv` | Итоговые отличия рабочей копии от оригинала, включая несопоставленные колонки |
| `summary.xlsx` | Те же таблицы на отдельных листах; ячейки записаны текстом |
| `report.json` | Файлы, строки, дата с часовым смещением сервера, правила, ошибки, устранённые/новые проблемы, статус |
| `READ_ME.txt` | Статус и пояснения к экспорту |

ZIP содержит весь комплект. `raw_json` сохраняет все оригинальные колонки; `working_json` — все колонки рабочей копии после ручных правок. Выбранные нормализованные поля находятся отдельно. Неизвестные колонки не теряются. Каталог содержит **A и B**, а не автоматически объединённый магазинный прайс.

CSV: UTF-8 с BOM, `;` или `,`, кавычки и переносы сохраняются. Опасные текстовые префиксы `= + - @` и управляющие символы получают защитный апостроф. Подтверждённые числовые поля не получают его. Защищённый CSV намеренно не идентичен опасному исходному тексту; точный оригинал доступен в `raw_json`. Для Excel предпочтителен XLSX; при импорте CSV задайте SKU тип «Текст», чтобы сохранить ведущие нули. Формулы XLSX не выполняются.

## Приватность и ограничения

- Обработка выполняется **на локальном Python-сервере**, не в браузере. Файлы передаются только на `127.0.0.1`; облачных API, аналитики, CDN, платных сервисов и аккаунтов нет.
- Принятые загрузки, рабочие копии и экспорт хранятся в памяти процесса. Порог временного буфера multipart превышает допустимый запрос; загрузка более 1 МБ без сброса на диск проверяется тестом. localStorage/постоянное хранилище не используются. Защищённое стирание памяти ОС не гарантируется.
- «Почати заново» удаляет сессию. Закрытие вкладки не очищает сервер немедленно. Неактивные сессии очищаются при следующем запросе после часа; завершение сервера уничтожает состояние процесса. Скачанные вами файлы остаются на диске. Максимум шесть сессий.
- На файл: **2 МБ, 2000 записей данных, 64 колонки, 1000 символов на поле, 30000 символов JSON-снимка строки**. XLSX: один выбранный лист, максимум 16 МБ распакованных данных и 1000 ZIP-элементов. XLS/XLSM, макросы и шифрованные книги не поддерживаются.
- Проверены 2000+2000 строк в CSV/XLSX, CSV с 64 колонками и файл 1 856 034 байта. Измерения — `artifacts/performance.json`; это синтетический прогон на текущем компьютере, не гарантия скорости любого файла или устройства.
- Заголовки должны быть непустыми и уникальными. Повреждённые строки CSV с другим числом полей отклоняют импорт целиком, не теряются молча. Номер CSV — логическая запись с учётом заголовка, XLSX — строка выбранного листа. Пустые записи сохраняются.
- Автоопределение разделителя — эвристика, параметры показаны в просмотре. CP1251 выбирается вручную. Другие кодировки требуют предварительного преобразования.
- Excel мог заранее потерять точность/нули числового SKU. Простой формат `000000` восстанавливает отображаемые нули; числовой SKU отмечается предупреждением. Потерянную исходную точность восстановить нельзя.
- Это локальный инструмент без авторизации и многопользовательского сервера. Публикация и реальные интеграции не выполнялись. Данные пользователя не добавлялись в проект или Git.
